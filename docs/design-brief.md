# Premium Portfolio Design Brief

## Objective
Build a premium technical portfolio that helps recruiters quickly understand Jacob Allan's value as an ML/software/quant builder.

## Target audience
- Software engineering recruiters
- ML engineering recruiters
- Quant / finance / trading teams
- Startup founders or technical hiring managers

## Brand position
Engineering Science student at UofT building ML systems, full-stack AI tools, and quantitative software.

## Desired feeling
- premium
- restrained
- technical
- confident
- fast
- product-like

## Visual references
- Apple: spacing, typography, restraint
- OpenAI: calm technical minimalism
- Nike: confidence and visual energy, but not loud

## Avoid
- cyberpunk particles
- excessive neon
- generic gradient blobs
- template-like sections
- too many icons
- scroll-jacking
- heavy 3D
- weak screenshots

## Homepage structure
1. Hero
2. Featured project showcase
3. Case-study preview grid
4. Experience / proof section
5. Technical stack
6. Resume + contact CTA

## Proof requirements
Each serious project should eventually include:
- screenshot
- short demo GIF or video
- architecture diagram
- metrics/proof block
- GitHub link
- live demo where possible

## Performance constraints
Use Core Web Vitals as guardrails:
- LCP <= 2.5s
- INP <= 200ms
- CLS <= 0.1

## Motion rules
Use motion only to improve clarity:
- subtle fade/slide reveal
- gentle hover depth
- image reveal
- sticky showcase if lightweight

Do not use:
- custom cursor
- particle universe
- scroll-jacking
- giant video backgrounds
